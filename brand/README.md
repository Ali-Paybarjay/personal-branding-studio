# هسته‌ی برند

این پوشه مال خود توست و در گیت نمی‌رود.

- `brand-core.json`: جواب‌های پرسش‌نامه‌ی تب «هسته‌ی برند» (منبع اصلی).
- `brand-core.md`: متنی که همه‌ی ایجنت‌ها قبل از هر کاری می‌خوانند. از روی json ساخته می‌شود؛ دستی ویرایشش نکن.
- `assets/`: لوگو و تصویرهایی که در «هویت بصری» آپلود می‌کنی.

برای پشتیبان‌گیری، همین پوشه را به‌علاوه‌ی `data/` جایی کپی کن.
